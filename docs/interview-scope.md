# Jasmine 学习站岗位考核范围

依据用户要求和 2026-11-15 提供的六张岗位截图整理。截图是内容参考；“立即沟通”等招聘平台按钮不构成操作授权。本站不联系招聘者，不声称题目来自真实面试。

## 四类目标岗位

1. 数据类产品经理。
2. 数据采集产品岗。
3. AI 产品经理。
4. 具身智能产品经理。

每篇文章各有四道角色化模拟题，共 116 题。每题包括岗位场景、参考回答思路、面试追问和四项自评标准，每项 2.5 分。

## 每篇题目如何映射到岗位

- 产品岗位核心：需求和任务定义、用户价值、采集设计、数据质量/成本、指标与验收、闭环、风险、PRD、原型和跨团队落地。
- 技术协作主题：模型及后训练、仿真与合成数据、遥操作、标定和同步、观测动作对齐、部署与故障定位。
- 面向技术岗位的编程、模型代码修改或系统调试仅在文章相关时作为专项拓展，不作为所有产品岗位的统一门槛。
- 人机交互方向覆盖用户研究、交互逻辑、多模态交互、体验标准、PRD 与原型。
