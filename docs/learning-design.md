# Jasmine 学习站设计与内容约定

完整名称：**Jasmine｜Embodied Intelligence Learning Station**。主要语言为中文。线上地址为 `https://robolearning.carcagem.online/`。

## 用户与目标

面向希望系统理解具身智能、并准备数据类产品经理、数据采集产品岗、AI 产品经理或具身智能产品经理岗位的学习者。主要任务是找到阅读起点、按时间学习、检索概念、用模拟面试和产品练习检验理解。

## 目录范围

29 篇文章：入门 9、进阶 16、实战 4。首篇为 PKU EPIC Lab 的 [具身智能科研入门指南](https://github.com/jiangranlv/embodied-ai-start)，其余文章按用户提供的知乎 AI 蓝宝书目录建立。每篇保留可访问的原文链接和 GitHub 清单出处。

## 主页结构

首屏 → 三阶段学习路径 → 可搜索阅读清单 → 学习方法与逐词宣言 → 六组岗位能力 → FAQ → 页脚。主页主要 CTA 为开始学习。卡片和列表直达各篇独立页面。

## 每篇文章结构

面包屑与目录 → 标题、作者、介绍和来源入口 → 原文通读、精读笔记、面试练习、可选实践时间 → 学习目标 → 内容总结 → 重点讲解与术语 → 产品练习 → 四类岗位的模拟面试 → 原文、GitHub 与参考资料 → 前后篇导航。

每题是本站自编练习，不声称来自真实企业面试。题目紧扣岗位职责，把技术知识转为任务定义、采集 SOP、数据质量、成本、指标、验收、闭环、PRD、原型、部署协作与风险处理。答题区提供参考结构、追问和 10 分自评。

## 来源与版权

原文全文和图表不复制到本站；站内内容独立撰写并提供原文链接。不得将公开可访问误认为允许全文转载，尤其是 PKU EPIC Lab 仓库注明版权及商业传播限制的材料。

## 视觉和无障碍

采用浅色编辑式布局、Manrope 自托管字体、Phosphor 图标、绿/蓝/紫阶段标记及暖色强调。布局优先适配手机；语义化导航、键盘焦点、跳过导航、减少动态效果和清晰空状态均已实现。构建为独立静态页，避免文章链接依赖前端路由回退。

## SEO / AEO

主页和 29 篇文章页开放索引；隐私、条款和 404 页 noindex。每页有独立标题、描述、canonical、Open Graph 元数据。站点地图包含 30 个主要学习页面。
